    Service display names
    Services the directory found (hunt groups, call centers, auto attendants…). Pick one and give it the name you want to see instead of its ID. Saved right away; applies to the Team tab, boards, speed dials and transfer.
    Group display names
    The groups people belong to (shown as Group in a person's details, e.g. 3149647G). Give each the name you want to see, e.g. a site or region. Saved right away; also searchable.

    Add it to your browserDownload extension zip
    1. On the extensions page, turn on Developer mode.
    2. Drag the downloaded zip onto that page.
    3. Pin Telvoro from the puzzle-piece menu.
    Custom extension build
    When the extension files change, Telvoro saves a new zip to Downloads and the extension asks you to drop it again. Alternative: "Load unpacked" with the folder — that copy updates itself.
